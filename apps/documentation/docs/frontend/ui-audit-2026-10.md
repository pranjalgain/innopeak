# Frontend UI audit, October 2026

Read-only audit of `apps/web` by a separate agent (accessibility, i18n, responsive layout, states, forms, navigation, performance, conventions). It read the code and
did not render or sign in, so contrast figures (its own oklch to sRGB conversion, about ±0.1), German overflow estimates and the header overflow are inferred. The en and
de key trees match exactly (1025 leaf strings, same ICU argument names), so the i18n findings are hard-coded strings, locale-blind formatting and wording.

**40 findings: 5 high, 25 medium, 10 low.** By area: 15 accessibility, 8 loading/error state, 6 i18n, 6 responsive, 2 form, 2 navigation, 1 convention.

## Shared root causes

- `components/ui/dialog.tsx`: no `max-h`/scroll (ui-4), hard-coded "Close" (ui-17), 16px close target (ui-30), overshoot/zoom animation with no reduced-motion guard (ui-13).
- Forms: `components/ui/form.tsx` is unused and `{!isValid || …}` disabled-submit is the rule everywhere (ui-8, ui-9, ui-11); one pattern fix covers ~14 forms.
- Switch, Slider, Progress, ToggleGroup have no naming convention (ui-10); fix in the primitives with a required `aria-label` prop.
- `globals.css` tokens (ui-12) and no reduced-motion block plus unconditional `scroll-behavior` (ui-13).
- `components/ui/button.tsx:9` `dark:text-white` damages the `link` variant and forces white on primary in dark mode (ui-12, ui-29).
- `AppShell`/`AppHeader`/`sidebar.tsx`: collapsed-rail labels, nested `<main>`, no `aria-current`, unnamed avatar trigger, header overflow, breakpoint remount (ui-2, ui-14, ui-19, ui-20, ui-27).
- `components/ui/card.tsx` `CardTitle` is a `div`, so no card has a heading (ui-27).
- `components/common/star-rating.tsx` (ui-16) and `password-input.tsx` (ui-15) are shared and used on many screens.
- `sonner-toaster.tsx` 2 s duration (ui-21), combined with queries that have no in-page error state (ui-5, ui-6, ui-40).

## i18n key diff

- Missing from de.json: none. Missing from en.json: none. Identical trees, all plurals use `one`/`other`.
- German strings identical to English (all brand or sample data): `onboardingSignup.createAccount.businessNamePlaceholder`, `onboardingBusinessName.placeholder`, `promptManagement.summary.prompts`,
  `promptManagement.editor.characterCount`, `promptManagement.editor.sample.business_name`, `promptManagement.history.entryLabel`, `promptManagement.history.previewTitle`,
  `adminSettings.invite.emailPlaceholder`, `adminSettings.platform.microsoft.label`.
- Plural gaps: `settings.general.retention.suffix` (ui-39); `onboardingConnect.done.description` uses `{count}` unpluralised but only for count above 0.
- Hard-coded user-visible strings: `components/ui/dialog.tsx:68` "Close"; `sheet.tsx:71` "Close" and `sidebar.tsx:183,252,264,267` (dead code); `app/_libs/services/avatar-upload.service.ts:68,74,104,107`
  (English messages, mostly masked by the hooks); every page `metadata.title` (ui-28) and `(public)/page.tsx:39-41`; `global-error.tsx` carries its own en/de dictionary (acceptable).
- Formatting that ignores the locale: `math.ts:10`, `dashboard-view.tsx:45`, `String(count)` for dashboard and prompt stats.
